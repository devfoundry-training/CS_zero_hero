# Practice exercises

Short fill-in-the-blank exercises, one per topic. They used to live in `src/CS_zero_hero/Tasks/`, where their
blanks stopped the project from building, so they now live here, outside every project.

Each file says how to use it: create a new console project (`dotnet new console -n NAME`), copy the template into
its `Program.cs` and fill in each blank. The files here are never compiled as they are.

| File | Concepts practised |
|------|--------------------|
| 01_Fundamentals.cs | Project creation, CLI, .csproj |
| 02_Datatypes.cs | Value/reference types, nullable, boxing |
| 03_Operators.cs | Arithmetic, precedence, ternary |
| 04_Control_Flow.cs | Conditionals, loops, flow control |
| 05_Iteration.cs | Loop mastery, nested loops |
| 06_Collections.cs | Arrays, lists, dictionaries, sets |
| 07_String_Manipulation.cs | Cleaning, parsing, transformation |
| 08_Files.cs | File read/write, directories |
| 09_Exceptions.cs | Error handling, custom exceptions |
| InheritanceLab.cs | Shape hierarchy, virtual/override, polymorphism |

The end-of-session tasks for the course are in `tasks/` (see `tasks/README.md`).
